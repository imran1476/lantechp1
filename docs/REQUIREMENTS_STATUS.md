# প্রয়োজন বনাম বাস্তব অবস্থা (Requirements Status)

প্ল্যান PDF (P1 — ভূমিলিপি) ও ১৬ অক্টোবরের মিটিংয়ের সিদ্ধান্ত অনুযায়ী প্রতিটি দাবির সৎ অবস্থা।
চিহ্ন: ✅ করা ও পরীক্ষিত · 🟡 আংশিক / শর্তসাপেক্ষ · ❌ করা হয়নি · ⬜ টিমের কাজ (কোডের বাইরে)

"পরীক্ষিত" মানে: `npm test` (১৫টি ইউনিট টেস্ট) ও `npm run test:api` (২৮টি এন্ড-টু-এন্ড চেক) পাস করেছে।
**ব্রাউজারে স্ক্রিন চালিয়ে দেখা এই পরীক্ষার অংশ নয়** — নিজের মেশিনে `npm run dev` দিয়ে একবার ঘুরে দেখুন।

| ৬ | সার্চযোগ্য ডেটাবেস | ✅ | `data/db.json` + ছবির ফাইল; রিস্টার্টেও থাকে। সার্চ শুধু **অনুমোদিত** রেকর্ডে (চাইলে বাকিগুলোও)। এটি JSON-ফাইল স্টোর, SQL ডেটাবেস নয় (প্রোটোটাইপের জন্য যথেষ্ট; বদলের জায়গা `server/store.ts`)। |

### নিয়মগুলোর বিস্তারিত

| নিয়ম | অবস্থা | মন্তব্য |
|---|---|---|
| ১ অঙ্ক স্বাভাবিকীকরণ | ✅ | সংরক্ষণের সময় বাংলা → ইংরেজি অঙ্ক স্বয়ংক্রিয়; পড়া না গেলে লাল |
| ২ অংশের যোগফল = ১ | ✅ | `১/২`, `০.৫`, `৮ আনা`, `৫০%` সমর্থিত; পড়া না গেলে **লাল** (আগে নীরবে পাস করত) |
| ৩ ক্ষেত্রফলের যোগফল = মোট জমি | ✅ | একর/শতক/কাঠা শতকে রূপান্তর করে মেলানো (আগে একক উপেক্ষা করত) |
| ৪ এককের সামঞ্জস্য | ✅ | মেশানো একক = হলুদ, অজানা একক = লাল; ১ একর = ১০০ শতক। **১ কাঠা ≈ ১.৬৫ শতক ধরা হয়েছে, অঞ্চলভেদে বদলায়** — মেন্টরকে দিয়ে মিলিয়ে নিন |
| ৫ বৈধ জরিপ | ✅ | CS / SA / RS / BS |
| ৬ বাধ্যতামূলক ফিল্ড | ✅ | মৌজা, খতিয়ান, দাগ, মালিক = লাল; জেলা/উপজেলা = হলুদ |
| ৭ একই দাগ একাধিক খতিয়ানে | ✅ | একই মৌজা+জরিপে অন্য খতিয়ানে একই দাগ থাকলে মোট অংশ > ১ হলে হলুদ; ভাগাভাগি দেখাতে দাগে ঐচ্ছিক "দাগের অংশ" দিন। ডুপ্লিকেট খতিয়ান নম্বরও ধরে। **বাস্তব ভূমি-আইনের সাথে মেলে কি না ফ্যাকাল্টিকে দেখিয়ে নিন** (প্ল্যানের নিজের পরামর্শ) |
| ৮ কম কনফিডেন্স = হলুদ | ✅ | সীমা ৮০% (`CONFIDENCE_THRESHOLD`) |

## আগে যে ভুয়া/বিভ্রান্তিকর অংশ ছিল, এখন ঠিক করা

- লগইন: যে-কোনো বোতামে ঢোকা যেত → আসল লগইন
- ছবি-পরিষ্কারের টিকবক্স শুধু দেখানোর ছিল ("OpenCV/Pillow" লেখা) → আসল ও সৎ লেবেল
- যাচাই প্যানেলে "৬/৬ পাস" স্থির লেখা ও স্থির সতর্কবার্তা → আসল ফল
- যে-কোনো আপলোডে একই সাভার নমুনা রেকর্ড চুপচাপ আসত → "ডেমো ডেটা" সতর্কতা
- "মূল স্ক্যান" জায়গায় সবসময় একই নকল নথি → আপলোড করা আসল ছবি (না থাকলে "নমুনা চিত্র" লেবেলসহ)
- "SHA-256" লেবেলে ৩২-বিটের স্থির হ্যাশ → আসল SHA-256 হ্যাশ-চেইন
- ভুয়া QR ও "ই-নামজারি" দাবি → সরানো
- জরিপ-সংযোগ স্থির লেখা → আর্কাইভ থেকে হিসাব করা
- রিফ্রেশে ডেটা হারানো → সার্ভারে স্থায়ী
- অনুমোদনে কোনো যাচাই-বাধা ছিল না, ক্লায়েন্ট নিজেই সব ঠিক করত → সার্ভার আবার যাচাই করে, ভুলে আটকায়
- ড্যাশবোর্ডের সংখ্যা স্থির → আসল রেকর্ড গুনে

## আমি যা জানি না / যাচাই করিনি

- আসল Gemini OCR কেমন চলে; মডেলের নাম (`gemini-3.8-flash`, `GEMINI_MODEL` দিয়ে বদলানো যায়) আসলে আপনাদের অ্যাকাউন্টে আছে কি না
- ব্রাউজারে সম্পূর্ণ UI (লেআউট, ডার্ক মোড, মোবাইল) — আমি Vite বিল্ড/ব্রাউজার চালাতে পারিনি
- ছবি-পরিষ্কার আসল স্ক্যানে কতটা কাজ করে (শুধু গণিত টেস্ট হয়েছে)
