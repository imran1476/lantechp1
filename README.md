# ভূমিলিপি (BhoomiAI) — LandTech ২০২৬ · প্রথম রাউন্ড · P1

স্ক্যান করা পুরোনো খতিয়ান ও পর্চা থেকে **যাচাইকৃত, অনুসন্ধানযোগ্য ভূমি-ডেটা** তৈরির প্রোটোটাইপ।

**প্রবাহ:** লগইন → আপলোড (ছবি পরিষ্কার) → বাংলা OCR → ফিল্ড নিষ্কাশন → স্বয়ংক্রিয় যাচাই (৮টি নিয়ম) → মানুষের পর্যালোচনা ও অনুমোদন → অনুসন্ধানযোগ্য আর্কাইভ (হ্যাশ-চেইন অডিট লগসহ)।

> সব ডেটা কাল্পনিক। কোনো আসল ব্যক্তির নাম, NID, ফোন, ঠিকানা বা আসল ভূমি রেকর্ড ব্যবহার করবেন না।

প্রয়োজন বনাম বাস্তব অবস্থার সৎ তালিকা: [`docs/REQUIREMENTS_STATUS.md`](docs/REQUIREMENTS_STATUS.md)

## চালানোর নিয়ম

প্রয়োজন: Node.js 20.19+ (অথবা 22.12+)

```bash
npm install
cp .env.example .env.local     # AUTH_SECRET বসান (চাইলে GEMINI_API_KEY-ও)
npm run dev                    # http://localhost:3000
```

প্রোডাকশন: `npm run build` তারপর `NODE_ENV=production npm start` (`AUTH_SECRET` বাধ্যতামূলক)।

## লগইন ও রোল

লগইন ছাড়া কোনো স্ক্রিন বা `/api` রুট খোলে না। ডেমো পাসওয়ার্ড: `Bhoomi@2026` (`.env`-এ বদলানো যায়)। ইউজার তিনটিই কাল্পনিক।

| ইউজারনেম | রোল | কী করতে পারে |
|---|---|---|
| `operator` | ডিজিটাইজেশন অপারেটর | আপলোড, তথ্য সংশোধন |
| `reviewer` | যাচাইকারী কর্মকর্তা | সংশোধন, **অনুমোদন/প্রত্যাখ্যান** |
| `admin` | প্রশাসক | সব |

রোল-নিয়ম **সার্ভারে** প্রয়োগ হয় (শুধু বোতাম বন্ধ করা নয়)।

## স্বয়ংক্রিয় যাচাই (নিয়ম ১–৮)

`src/utils/validation.ts` — ক্লায়েন্ট ও সার্ভার একই কোড চালায়। **অনুমোদনের সময় সার্ভার নিজে আবার যাচাই করে; "ভুল" (লাল) থাকলে রেকর্ড অনুমোদিত হয় না**, "সতর্কতা" (হলুদ) মানুষ দেখে নিশ্চিত করে।

১ বাংলা অঙ্ক স্বাভাবিকীকরণ · ২ অংশের যোগফল = ১ · ৩ দাগের ক্ষেত্রফলের যোগফল = মোট জমি (শতকে রূপান্তর করে) · ৪ এককের সামঞ্জস্য (১ একর = ১০০ শতক; ১ কাঠা ≈ ১.৬৫ শতক ধরা, অঞ্চলভেদে ভিন্ন) · ৫ বৈধ জরিপ (CS/SA/RS/BS) · ৬ বাধ্যতামূলক ফিল্ড · ৭ একই দাগ একাধিক খতিয়ানে / ডুপ্লিকেট · ৮ কম OCR কনফিডেন্স (< ৮০%)

নিয়মগুলো আমাদের কাল্পনিক ডেটার জন্য সাজানো; বাস্তব ভূমি-নিয়মের সাথে (বিশেষ করে ৭ নম্বর) ফ্যাকাল্টি/মেন্টরকে দিয়ে মিলিয়ে নিতে হবে।

## অন্যান্য বৈশিষ্ট্য

- **ছবি পরিষ্কার** (ব্রাউজারে, আপলোডের আগে): কাত সোজা, ৩×৩ মিডিয়ান নয়েজ কমানো, কনট্রাস্ট। শুধু JPG/PNG।
- **দাগ-তালিকা সম্পাদনা ও লাইভ যাচাই**: প্রতিটি দাগের শ্রেণি, ক্ষেত্রফল, একক, (ঐচ্ছিক) দাগের অংশ।
- **বাংলা ফাজি সার্চ** (`src/utils/banglaSearch.ts`): মোঃ/মো/মোহাম্মদ/Md., ই-ঈ, শ-ষ-স ইত্যাদি একীভূত; ফল স্কোর অনুযায়ী সাজানো। সার্চ শুধু অনুমোদিত রেকর্ডে (চাইলে বাকিগুলোও)।
- **জরিপ ক্রস-লিংকিং** (`src/utils/linking.ts`): একই মৌজা ও দাগের CS/SA/RS/BS জোড়া, মিল % হিসাব করা। প্রাথমিক heuristic।
- **স্থায়ী ডেটা**: `data/db.json` ও `data/uploads/` — রিফ্রেশ বা রিস্টার্টে থাকে। (JSON-ফাইল স্টোর; পরে PostgreSQL — বদলের জায়গা `server/store.ts`)
- **SHA-256 হ্যাশ-চেইন অডিট লগ** (`server/integrity.ts`): প্রতিটি লগের হ্যাশ আগের লগের সাথে জোড়া। "অখণ্ডতা যাচাই" বোতাম লগ বা রেকর্ডের তথ্য বদলালে ধরে।
  **সীমা:** ডেটা-ফাইলে পূর্ণ অ্যাক্সেসওয়ালা কেউ সব হ্যাশ নতুন করে বানিয়ে দিলে ধরা পড়বে না; তার জন্য হ্যাশের মাথা (head hash) বাইরে আলাদা জায়গায় রাখতে হয়।
- **এক্সপোর্ট**: CSV (বাংলা ঠিক রেখে) ও JSON।

### API (সব লগইন-সুরক্ষিত)
`GET /api/records` · `POST /api/records` (operator/admin) · `PUT /api/records/:id` · `POST /api/records/:id/approve|reject` (reviewer/admin) · `GET /api/records/:id/verify` · `GET /api/records/:id/image` · `POST /api/ocr-extract` (operator/admin) · `POST /api/auth/login|logout`, `GET /api/auth/me`

## ভাষা

ডিফল্ট **বাংলা**; হেডার/লগইনের **বাংলা | English** বোতামে বদলানো যায়। অনুবাদ `src/i18n/translations.ts`-এ। ইংরেজি এখন লগইন, মেনু, হেডার, ধাপ, শিরোনামে আছে; পেজের ভেতরের ফর্ম/টেবিল শুধু বাংলা (দ্বিতীয় অগ্রাধিকার)।

## নিরাপত্তা (`server/auth.ts`)

scrypt পাসওয়ার্ড হ্যাশ · HMAC-সই করা সেশন, `httpOnly` + `SameSite=Strict` কুকি (৮ ঘণ্টা; লগআউটে বাতিল) · ৫ বার ভুলে ১৫ মিনিট লক · বডি পার্স করার **আগেই** লগইন/রোল যাচাই · শুধু JPG/PNG/PDF, ~১০ MB · ক্রস-সাইট POST আটকানো · নিরাপত্তা হেডার · ছবি শুধু লগইন করা ব্যবহারকারীকে · লগে পাসওয়ার্ড/টোকেন নেই · ভেতরের এরর ক্লায়েন্টকে দেওয়া হয় না।

## OCR সম্পর্কে সৎ কথা

- `GEMINI_API_KEY` থাকলে সার্ভার ছবি পাঠিয়ে বাংলা OCR ও ফিল্ড নিষ্কাশন করে। মডেলের নাম `GEMINI_MODEL` দিয়ে বদলানো যায়; ডিফল্ট নাম আপনাদের অ্যাকাউন্টে আছে কি না যাচাই করুন। **আসল OCR আমরা (কোড লেখার সময়) চালিয়ে দেখিনি।**
- চাবি না থাকলে বা কল ব্যর্থ হলে **কাল্পনিক ডেমো রেকর্ড** আসে এবং স্ক্রিনে "ডেমো ডেটা" সতর্কতা দেখায়।
- ফিল্ডের কনফিডেন্স সংখ্যা মডেলের নিজের অনুমান, আসল OCR কনফিডেন্স নয়।
- নির্ভুলতা মাপতে: `node scripts/eval-ocr.mjs http://localhost:3000 operator Bhoomi@2026` (`samples/`-এর ১০টি কাল্পনিক ছাপা নমুনায়)। **কোনো সংখ্যা আমরা দাবি করছি না** — নিজেরা মেপে নমুনার আকারসহ লিখুন। হাতে-লেখা নমুনা নিজেদের বানাতে হবে।

## জানা সীমাবদ্ধতা

- ব্যবহারকারী তালিকা সার্ভারের মেমরিতে (৩টি ডেমো অ্যাকাউন্ট); নতুন ইউজার/পাসওয়ার্ড পরিবর্তন নেই
- সেশন টোকেন stateless; সার্ভার রিস্টার্টে (AUTH_SECRET না দিলে) সবাই লগআউট
- স্টোর একক-প্রসেসের জন্য; একাধিক সার্ভারে চালাতে ডেটাবেস লাগবে
- লেগ্যাসি ফন্ট → ইউনিকোড, ই-নামজারি/নিবন্ধন API সংযোগ করা হয়নি
- ছবি-পরিষ্কার PDF-এ চলে না

## AI Tools Used (জমা দেওয়ার নিয়ম অনুযায়ী ঘোষণা)

> নিচেরটা আপনাদের আসল ব্যবহার অনুযায়ী মিলিয়ে ঠিক করে নিন।

- **Google AI Studio / Gemini** — অ্যাপের প্রথম কাঠামো ও OCR রুট (প্রজেক্টের মূল কোড)
- **Claude (Anthropic)** — মিটিংয়ের সিদ্ধান্ত অনুযায়ী আপডেট: লগইন ও রোল, বাংলা/English সুইচ, নিয়ম ১–৮-এর নতুন রুল ইঞ্জিন, স্থায়ী স্টোর ও SHA-256 হ্যাশ-চেইন, ছবি-পরিষ্কার, ফাজি সার্চ, জরিপ-লিংক, রিভিউ/বিস্তারিত স্ক্রিনের পুনর্লিখন, টেস্ট, নমুনা ছবি, নথি
- রানটাইমে `GEMINI_API_KEY` দিলে Gemini মডেল ছবি থেকে লেখা ও ফিল্ড বের করে

টিমের প্রত্যেক সদস্যকে প্রতিটি অংশ ব্যাখ্যা করতে পারতে হবে; বিচারকরা যে কাউকে প্রশ্ন করতে পারেন। শুরু করতে `docs/REQUIREMENTS_STATUS.md` ও ওপরের "ফাইলের গঠন" পড়ুন।
