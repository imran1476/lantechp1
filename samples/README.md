# নমুনা ছবি (সব কাল্পনিক)

`khatian_01.png … khatian_10.png` — কম্পিউটারে বানানো **ছাপা** কাল্পনিক খতিয়ান (নাম/মৌজা/জেলা সব বানানো)।
কিছু ছবি ইচ্ছাকৃত কাত বা নয়েজযুক্ত (ছবি-পরিষ্কার পরীক্ষার জন্য)। `khatian_06` তে মোট জমি ভুল (নিয়ম ৩), `khatian_08` তে অংশের যোগফল ভুল (নিয়ম ২) — ছবিতে ইচ্ছা করেই বসানো, এগুলো সিস্টেমের ধরার কথা।

`ground_truth.json` — প্রতিটি ছবির সঠিক উত্তর (injectedError ফিল্ড দেখায় কোনটায় ভুল বসানো)।

## সীমাবদ্ধতা (সৎ কথা)
- এগুলো কেবল ছাপা-ধাঁচের সিনথেটিক ছবি; **হাতে লেখা নমুনা নেই** — প্ল্যান অনুযায়ী ২০–৩০টি আসল ছাপা + হাতে-লেখা (কাল্পনিক) স্ক্যান আপনাদের নিজেদের বানাতে হবে।
- এই ১০টি দিয়ে মাপা নির্ভুলতা **আসল পুরোনো খতিয়ানের নির্ভুলতা নয়**; রিপোর্টে "নিজেদের ১০টি সিনথেটিক নমুনায়" লিখে সংখ্যা দিন।
